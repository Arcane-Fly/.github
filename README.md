# Braden Group GitHub defaults

This public repository contains the [Arcane-Fly organization profile](profile/README.md) and default guidance for contributing, support, security reports, and pull requests.

GitHub shows these defaults in organization repositories that do not provide their own corresponding files. Follow a repository's own guidance when it differs. See [GitHub's explanation of default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
