# Reporting a security issue

Please report suspected vulnerabilities privately. Do not include exploit details, credentials, or personal information in a public issue, pull request, or discussion.

For the affected repository, use **Security → Advisories → Report a vulnerability** if that option is available. Otherwise, email [info@braden.com.au](mailto:info@braden.com.au) with the subject `Security report: <repository name>`.

Include the affected repository and version or URL, a concise description of the impact, and steps to reproduce using redacted or test data. We will review the report and coordinate next steps privately. Repository-specific security instructions take precedence over this default.
